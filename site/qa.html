Quality Assurance

Every merge to modelai-main is gated by adversarial review, automated CI, and benchmark verification. This page documents the full process.

Adversarial review protocol

Every implementation slice goes through a 13-section hostile review before merge. The reviewer's job is to try to break the code — not confirm it looks reasonable. This protocol has caught all 18 Critical/Major bugs in the fork's history.

Upstream sync process

Every Saturday at 2PM PDT, the automated sync workflow fetches the latest upstream llama.cpp and merges it through a CI gate. No upstream change reaches modelai-main without passing build + test + human review.

Step 1: Fetch and merge
  1. Fetch latest upstream/master
  2. Update upstream-master tracking branch
  3. Reset upstream-sync to modelai-main
  4. Merge upstream into upstream-sync
Step 2: CI gate
  1. Full cmake build (Metal + tests + examples)
  2. Run all 49 main-label tests
  3. Benchmark regression check vs baseline
  4. Pass: merge into modelai-main
  5. Fail: open GitHub Issue with diagnostics

Manual review gate

When the upstream delta touches compaction-related files (KV cache, graph construction, attention paths), the merge is held for manual review. The reviewer checks:

  1. API compatibility — Do upstream KV cache changes break compacted prefix integration?
  2. Graph construction — Do attention graph changes require updates to compacted execution?
  3. Architecture support — Do new model architectures need compaction support?
  4. Test coverage — Do new upstream tests exercise compacted paths?
  5. Security patches — CVE fixes are fast-tracked for same-day sync

6 upstream KV cache changes audited and verified compatible: #10873, #12695, #13194, #17450, #12253, #11213. RPC RCE security patch synced within hours of upstream disclosure.

3-branch model

modelai-main
Working branch. All development and releases. Protected: requires PR review + status checks.
upstream-master
Clean upstream tracking. Force-updated to match upstream/master on every sync.
upstream-sync
Staging branch. Reset to modelai-main, merged with upstream, then CI-gated before integration.
