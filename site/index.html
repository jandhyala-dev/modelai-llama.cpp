LLMs forget long conversations.
We fixed that.

When an AI model runs out of memory mid-conversation, it throws away the oldest context and forgets what you said. modelai-llama.cpp compresses that memory instead of discarding it — shrinking earlier parts of the conversation into a compact summary that stays in context, so nothing is lost. The model keeps the full conversation, runs faster, and produces nearly identical output.

This means a retail laptop with 16GB of RAM can hold conversations that previously required 64GB or a cloud API — local models stay coherent through hour-long analysis sessions instead of losing track after ten minutes. Built on research from MIT, implemented in production C++, and validated across 15 models.

The problem

Every AI model stores conversation history in a memory buffer called the KV cache. As conversations grow, this buffer fills up. Today's solutions — truncation and sliding windows — deal with this by deleting the oldest context. The model literally forgets what you said earlier.

There's a second problem: the larger this memory buffer, the slower the model runs. Attention computation scales with buffer size, so long conversations degrade performance even when everything still fits.

The solution

Instead of deleting old context, compress it. KV cache compaction, based on Attention Matching from MIT (Zweiger et al., 2026), replaces the full memory buffer with a smaller, mathematically optimized representation that preserves the model's behavior. The compressed version isn't a subset of the original — it's a new set of synthetic key-value pairs that reproduce the same attention pattern.

How compaction works

The algorithm runs in four stages, all in pure C++ with zero external dependencies:

1 Select the most important positions

Score each position by how much attention it receives. Keep the top M out of N total. The production-default select pipeline runs in 62–185ms and is flash-attention compatible.

2 Fit correction terms

Solve for additive bias terms (beta) that correct the attention distribution after selection. Uses Non-Negative Least Squares with regularized Cholesky decomposition.

3 Fit compressed values

Solve for new value tensors so the attention-weighted output matches the original. Uses a 3-tier cascade: LAPACK QR, Cholesky, or aggressive Cholesky fallback.

4 Prepend and continue

Compacted tensors are prepended to the live KV cache during attention. Freed slots accept new tokens. The model continues with full context preserved.

Why a fork?

The upstream llama.cpp doesn't have KV compaction. The MIT paper provides a Python reference, but production use requires a complete C++ implementation integrated into llama.cpp's KV cache, graph construction, and server infrastructure. This fork is that implementation.

Pure C++
Complete solver with zero external dependencies. Optional LAPACK on macOS, Cholesky fallback everywhere else. NEON SIMD + Metal GPU on Apple Silicon.
Drop-in compatible
Same build system, same flags, same API. Add --endpoint-compact to enable. Without it, the fork behaves identically to upstream.
Weekly upstream sync
Automated Saturday sync, CI-gated. Security patches synced same-day. 6 upstream KV cache changes audited and verified compatible.

Getting started

# Build (same as upstream llama.cpp) git clone https://github.com/jandhyala-dev/modelai-llama.cpp cd modelai-llama.cpp cmake -B build -DGGML_METAL=ON cmake --build build --config Release -j$(nproc) # Run with compaction enabled ./build/bin/llama-server -m model.gguf --endpoint-compact -c 8192 # Trigger compaction via REST API curl -X POST http://localhost:8080/compact \ -H "Content-Type: application/json" \ -d '{"id_slot": 0, "method": "select", "ratio": 4.0}' # Or use auto-compaction (fires when memory reaches threshold) ./build/bin/llama-server -m model.gguf --endpoint-compact --compact-threshold 0.9 -c 8192

Public C API

// Trigger compaction programmatically struct llama_compact_params params = llama_compact_default_params(); params.method = LLAMA_COMPACT_SELECT; params.ratio = 4.0f; llama_kv_cache_compact(ctx, params); // Or set auto-compaction threshold llama_kv_cache_set_auto_compact(ctx, 0.9f);
