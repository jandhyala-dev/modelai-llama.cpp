High-compression benchmark

Iterative on-policy refinement enables extreme compression ratios while maintaining near-perfect quality.

50x
compression

Qwen3-30B-A3B compressed at 50x ratio with 0.9967 cosine similarity and 10/10 fact recall. Achieved through iterative on-policy refinement with quality-gated convergence. 256K effective context from 64K physical memory through 49-57 compaction cycles — 100% recall verified at every checkpoint.

Decode speed after compaction

Compaction shrinks the KV cache, which means attention runs over fewer tokens. The result is faster decoding — up to 63% faster at 8x compression.

Fork vs upstream vs Ollama (no compaction)

When compaction is not active, the fork matches upstream llama.cpp within measurement noise. No performance regression from having compaction code in the binary. The MoE model (Qwen3-30B-A3B) runs 13% faster than Ollama at baseline.
